This is a one-page portfolio site for a freelance photographer named Alex Reyes.
Dark, minimal, fast. Static HTML/CSS/JS only — no frameworks, no build step.
All images are placeholders from https://picsum.photos.

## Prompt 1 — scaffold the site

Create the project skeleton: index.html, css/styles.css, js/main.js.
Semantic HTML5 layout with header, nav, main, footer. Mobile-first CSS with a
dark palette and one accent color. Wire the stylesheet and script up and make
sure the page opens cleanly in a browser.

## Prompt 2 — hero and gallery

Build the hero section (name, one-line tagline, call-to-action button that
scrolls to the gallery) and a responsive photo gallery: a grid of 9 placeholder
images that opens a lightbox on click (plain JS, no libraries). Keyboard
navigation (arrows + Escape) in the lightbox.

## Prompt 3 — about and contact

Add an About section (short bio, portrait placeholder) and a Contact section
with a mailto link and social icons (inline SVG). Smooth-scroll navigation
between all sections; highlight the active section in the nav.

## Prompt 4 — polish and ship-readiness

Add meta description, Open Graph tags, a favicon (inline SVG data URI is fine),
lazy-loading on gallery images, and a footer with the current year computed in
JS. Make sure the page has no console errors and looks right at 360px, 768px,
and 1440px widths.
